# Week Optimization System
An app for helping organize and plan your calendar given a list of things you want to get done.

Hackathon entry for Hacknite Fall 2026 at UC.

![image](/repo/images/image.png)

## Features
- Connect to your Google Calendar
- Enter commitments, goals, and tasks for the next week
- Gemini identifies the best places in your week to schedule these tasks for you
